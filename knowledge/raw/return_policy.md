# Return Policy

## Window
Returns use calendar days from verified delivery, inclusive on the final day. The default return window is 30 days. Footwear and apparel have 30-day windows, home products have 30 days, and electronics have 15 days. An undelivered order has not started its return window. The earlier reported 60-day window is not current; use this version and disclose the discrepancy.

## Condition
For review, provide the order reference and describe the item condition. The agent must not infer condition or approve an exception. Eligibility is computed from the verified order and configured rules, not a customer-supplied delivery date.

## Exclusions
Perishable grocery products, including the Gourmet Cheese Box, are excluded from returns. No live-animal, kayak or other unlisted-product-specific policy is defined. Missing policy requires clarification or abstention, not a generic eligibility promise.

## Restocking
Opened electronics have a 10% restocking fee under the configured electronics_opened rule. Do not infer that an item is opened. Missing condition evidence requires clarification or review.

## Exceptions
Requests for an exception on an ineligible item require human review. Product injury or safety complaints always require safety escalation. This agent provides eligibility information; it does not create returns or issue refunds.
